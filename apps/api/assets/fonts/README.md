# Шрифты PDF

Неизменённые Lato Regular и Bold из официального репозитория Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/lato
- Лицензия SIL Open Font License 1.1 — в `OFL.txt`, как и у шрифтов интерфейса.

Файлы поставляются вместе с API и встраиваются в PDF подмножествами. При скачивании отчёта внешних запросов за шрифтами нет. Зарезервированное имя Lato сохранено; шрифты не модифицированы.
