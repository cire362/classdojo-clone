# Герои класса

Веб-сервис для преподавателя: баллы за поведение и активность, у каждого ученика свой супергерой, а присутствующих можно отметить по фото группы. Интерфейс на русском, работает с телефона и на проекторе.

- **Преподаватель** ведёт группы, начисляет и списывает баллы, отмечает посещаемость по фото, смотрит статистику и выгружает её в Excel.
- **Ученик** входит по выданному логину, собирает своего героя, видит уровень, баллы, историю и посещаемость.

## Быстрый старт

Нужен Docker с Compose.

```bash
docker compose up --build
```

Откройте http://localhost:8080. Первая сборка скачивает модели YOLOX (~140 МБ), поэтому занимает несколько минут.

При первом запуске seed создаёт тестовые данные:

| Кто | Логин | Пароль |
|---|---|---|
| Преподаватель | `teacher` | `teacher123` |
| Ученики группы «5 «А»» (10 человек) | `alisa.m`, `artem.k`, `vera.s`, `gleb.n`, `darya.l`, `egor.p`, `zlata.v`, `ilya.f`, `kira.m`, `mark.o` | `hero12345` |
| Родитель Киры и Марка | `parent` | `parent12345` |

Пароли seed задаются переменными `SEED_TEACHER_PASSWORD` и `SEED_STUDENT_PASSWORD` в `docker-compose.yml`. Seed идемпотентен: если преподаватель уже есть, данные не трогаются.

Чтобы начать с чистой базы, удалите том: `docker compose down -v` (все данные будут потеряны).

## Состав

| Сервис | Стек | Что делает |
|---|---|---|
| `web` | React, TypeScript, Vite, Tailwind v4, Motion, nginx | Интерфейс, проксирует `/api` в бэкенд |

| `detector` | Python, FastAPI, ONNX Runtime, YOLOX | Считает людей на фото (без распознавания лиц), только CPU |

## Как создать преподавателя

```bash
docker compose exec api npm run create-teacher -- --login ivanova --name "Анна Ивановна"
```

Пароль будет сгенерирован и выведен один раз. Можно задать свой: `--password "надёжный-пароль"`.

Сменить свой пароль и имя преподаватель может сам: «Настройки» (имя с шестерёнкой в шапке). Если пароль забыт, сбросить его можно из командной строки, добавив `--reset`.

Без Docker (из корня репозитория, с заданным `DATABASE_URL`):

```bash
npm run create-teacher -w @heroes/api -- --login ivanova --name "Анна Ивановна"
```

## Сценарий преподавателя

1. Войти как `teacher` → «Новая группа».
2. Вкладка «Ученики»: вставить список имён (по одному на строку) → «Добавить». Появится таблица логинов и паролей → «Распечатать».
3. Вкладка «Отметка»: «Сфотографировать» (на телефоне сразу откроется камера) или «Выбрать фото». Сервис покажет рамки и число людей. Снимите отметку с отсутствующих → «Сохранить». Каждый присутствующий получит +1 «Посещение».
4. Вкладка «Урок»: клик по герою → причина. «Всей группе» и «Несколько» начисляют баллы разом. «Случайный» выбирает ученика, «Проектор» открывает крупный режим без служебных кнопок.
5. Вкладка «Статистика»: период → таблица и «Скачать Excel».

## Новые детали героев

Все детали описаны в одном файле: [`packages/shared/src/hero/catalog.ts`](packages/shared/src/hero/catalog.ts). Деталь — это SVG-фрагмент на холсте 200×240, который накладывается поверх других слоёв.

1. Добавьте объект в массив `parts`:

   ```ts
   {
     id: 'emblem.moon',          // <слой>.<ключ>, уникальный
     layer: 'emblem',            // pose | suit | mask | cape | emblem | aura | hair | color | skin | hairColor
     name: 'Луна',               // название в конструкторе
     requiredLevel: 4,           // с какого уровня открывается
     front: BADGE + `<path d="..." ${EM}/>`,
   }
   ```

   - `front` рисуется поверх тела, `back` за телом (плащи, длинные волосы).
   - Цвета задавайте плейсхолдерами: `{suit}`, `{suitDark}`, `{accent}`, `{accentDark}`, `{skin}`, `{hair}`, `{outline}`. Тогда деталь подстроится под выбранные учеником цвета.
   - Для единого стиля обводите фигуры контуром: `stroke="{outline}" stroke-width="3" stroke-linejoin="round"` (константа `O` в файле).
   - Для цветов, тонов кожи и цвета волос вместо SVG задаётся `color: '#rrggbb'`.
   - Флаги масок: `hidesHair`, `hidesEyes`, `hidesMouth`, `overHair` (рисуется поверх причёски: корона, нимб).
   - Сияние (`aura`) рисуется самым первым слоем, за плащом и героем.
2. Перезапустите API (`docker compose up --build api web`): при старте каталог синхронизируется в таблицу `HeroPart`, и сервер начнёт принимать новую деталь.
3. Проверьте вид в конструкторе.

Только собственные детали: никаких персонажей, эмблем и узнаваемых костюмов из чужих франшиз.

Пороги уровней лежат в [`packages/shared/src/levels.ts`](packages/shared/src/levels.ts).

## Тесты

Бэкенд (баллы, уровни, права доступа, посещаемость, Excel). Работают с PostgreSQL из compose, каждый прогон использует свою временную схему и удаляет её после себя:

```bash
docker compose --profile test run --rm api-test
```

Сервис подсчёта (4, 7, 37 и ~57 человек на тестовых фото, большое фото с телефона, пустая сцена, поворот EXIF, ответ быстрее 3 секунд, отсутствие записи на диск):

```bash
docker compose run --rm --no-deps detector pytest -q
```

Фронтенд (Vitest + Testing Library: экран урока, отметка, конструктор героя, импорт, повторы при плохой связи):

```bash
npm test -w @heroes/web
```

### Сквозные тесты и полная проверка

Сквозные тесты (Playwright) проходят главный сценарий в браузере: группа → ученики → печать логинов → отметка по фото → баллы → статистика и Excel → ученик собирает героя. Отдельно проверяются права доступа, вёрстка на телефоне 375 px и отправка фото при обрывах связи. Каждый тест создаёт свою временную группу и удаляет её в конце.

Полная проверка одной командой: типы, тесты фронтенда, API, детектора и сквозные тесты. Она поднимает отдельный стенд на порту 8090, поэтому рабочий сайт на :8080 и его база не затрагиваются, а в конце стенд удаляется:

```bash
sh scripts/ci.sh
```

Только сквозные тесты против уже запущенного сайта на :8080 (браузер: установленный Chrome или `npx playwright install chromium`):

```bash
PW_CHANNEL=chrome npm run e2e
```

Те же проверки запускает GitHub Actions при каждом push: `.github/workflows/ci.yml`.

## Разработка без Docker

```bash
npm install
# Prisma 7 не читает .env сам: адрес базы должен быть в окружении
export DATABASE_URL=postgresql://user:pass@localhost:5432/heroes
npm run prisma:generate -w @heroes/api   # клиент Prisma генерируется в apps/api/src/generated
npm run db:migrate -w @heroes/api && npm run db:seed -w @heroes/api
DETECTOR_URL=http://localhost:8000 npm run dev:api     # API на :3000
npm run dev:web                                        # http://localhost:5173, /api проксируется на :3000
```

Сервис подсчёта локально: `cd services/detector && pip install -r requirements-dev.txt && python scripts/fetch_model.py yolox_m models && python scripts/fetch_model.py yolox_s models && uvicorn app.main:app --port 8000`.

## Приватность

- Распознавания лиц нет: сервис возвращает только число людей и рамки.
- Фото не сохраняется ни на диск, ни в базу: оно уменьшается в браузере, проходит через API в памяти и обрабатывается детектором в памяти. Контейнер детектора работает с файловой системой только для чтения. В базе остаются число людей на фото, дата и группа.
- Пароли хранятся как хеши argon2id, сессия в httpOnly cookie.
