# Roadmap «Героев класса»

Живой список того, что осталось сделать. Обновляется по ходу работы: новые идеи и найденные проблемы добавляются сюда, сделанное отмечается галочкой и переносится в раздел «Сделано» с датой.

**Сейчас главное — функционал.** Юридические вопросы и боевая инфраструктура отложены до решения о публичном запуске.

Как читать:
- **P0** — ближайшие функции, берём в работу первыми;
- **P1** — следующие функции;
- **P2** — технический долг;
- **Отложено** — понадобится перед публичным запуском;
- **Позже** — следующий этап продукта.

Почему приняты те или иные решения — в [DECISIONS.md](DECISIONS.md).

---

## P0. Ближайшие функции

- [ ] **Посещаемость за прошлую дату.** API уже принимает `date`, в интерфейсе нет выбора дня.
- [ ] **Смена пароля преподавателя в интерфейсе.** Сейчас только через CLI (`apps/api/src/cli/create-teacher.ts --reset`).
- [ ] **Перенос ученика в другую группу.**
- [ ] **Импорт учеников из Excel/CSV.**

## P1. Следующие функции

- [ ] **Несколько уроков в день.** Сейчас одна отметка на группу за день (`@@unique([groupId, date])`); добавить номер урока.
- [ ] **Порядок причин** перетаскиванием (поле `sortOrder` уже есть).
- [ ] **Архив групп** в конце учебного года вместо удаления.
- [ ] **Больше деталей героя на уровнях 6–10** (сейчас их там мало). Каталог: `packages/shared/src/hero/catalog.ts`.
- [ ] **Повтор загрузки фото** при плохом интернете на телефоне.
- [ ] **Точность подсчёта на больших классах.** На тестовом фото из 37 человек находится 33. Попробовать сетку тайлов 3×3 или модель YOLOX-L с проверкой, что ответ укладывается в ~3 с на CPU.

## P2. Технический долг

- [ ] **CI и сквозной тест.** Запуск тестов API, тестов детектора и проверки типов при каждом изменении; перенести в репозиторий браузерный сценарий (Playwright: группа → ученики → печать → фото → баллы → Excel → вход ученика).
- [ ] **Разделение бандла.** Скрипты фронтенда около 570 КБ одним файлом; загружать страницы преподавателя и ученика по требованию (`React.lazy`).
- [ ] **Тесты фронтенда** (компоненты конструктора героя, экрана урока).
- [ ] **Ограничение попыток входа в общем хранилище.** Сейчас счётчик в памяти процесса (`apps/api/src/auth.ts`); при нескольких копиях API перенести в PostgreSQL или Redis.
- [ ] **Аудит доступности и Lighthouse** (контраст, фокус, экранные дикторы).
- [ ] **Prisma 7.** Проект на Prisma 6; при переходе понадобятся `prisma.config.ts` и драйвер-адаптер.

## Отложено. Перед публичным запуском

- [ ] **152-ФЗ: персональные данные несовершеннолетних.** Согласие родителей, политика конфиденциальности, хранение базы на серверах в РФ, удаление данных ученика по запросу.
- [ ] **HTTPS и домен.** Обратный прокси с TLS (например, Caddy, Apache-2.0), `COOKIE_SECURE=true`.
- [ ] **Секреты из `.env`.** Пароли PostgreSQL и seed сейчас в `docker-compose.yml`; вынести в `.env`, добавить `.env.example`, отключить демо-seed в боевой среде.
- [ ] **Резервные копии PostgreSQL** с проверенным восстановлением.
- [ ] **Сбор ошибок и логов** в боевой среде (инструмент с лицензией, допускающей закрытое коммерческое использование).

## Позже. Следующий этап продукта

- [ ] **Несколько преподавателей в одной группе.**
- [ ] **Платные функции.** Задел: флаг `isPremium` у деталей героя.
- [ ] Сообщения, лента класса, уведомления, PWA, портфолио, магазин наград, командный режим.

## Сделано

- **2026-10-28. MVP.**
  - Монорепо и `docker compose up`.
  - Авторизация преподавателя и ученика.
  - Группы и ученики, генерация логинов, печать листа с паролями.
  - Экран урока: причины, начисление нескольким и всей группе, режим проектора, случайный выбор.
  - Модульный конструктор героев с уровнями.
  - Отметка по фото (YOLOX, без распознавания лиц, фото не сохраняется).
  - Кабинет ученика, статистика, выгрузка в Excel.
  - Тесты API и сервиса подсчёта.
- **2026-10-28. Экран входа:** без названия, слайдер героев справа.
- **2026-10-28. Приоритеты:** функционал вперёд, юридические вопросы и боевая инфраструктура отложены.
- **2026-10-28. Новый уровень и новые детали.**
  - Ученик при входе видит окно «Новый уровень!» с конфетти и открывшимися деталями.
  - Пока ученик не заглянул в конструктор, в кабинете висит баннер, а в меню показан счётчик новых деталей.
  - В конструкторе новые детали помечены «новое», вкладки с ними отмечены точкой.
  - На экране урока при переходе ученика на новый уровень его карточка подсвечивается.
  - Что ученик уже видел, хранится на сервере (`Student.celebratedLevel`, `partsSeenLevel`).
- **2026-10-28. Исправление истории.**
  - В профиле ученика у преподавателя у каждой записи есть кнопка удаления с подтверждением; баллы, уровень и статистика пересчитываются.
  - Баллы за посещение удалить нельзя: они меняются через отметку посещаемости (API отвечает 409).
  - Ученик кнопок удаления не видит, чужой преподаватель получает 404.
  - `DELETE /api/teacher/points/:id`.
